# Matrice d'Eisenhower

Outil web pour organiser ses tâches en quatre cases (Faire, Planifier, Expédier, Mettre de côté), présentées comme des pense-bêtes sur un tableau en liège. Il fonctionne sur ordinateur et sur smartphone.

- Onglets Pro, Perso et Vue globale, et autant d'onglets supplémentaires que nécessaire.
- Note de temps sur chaque tâche : elle donne la couleur du pense-bête et le délai de passage automatique en urgent avant l'échéance.
- Glisser-déposer des tâches d'une case à l'autre (appui long sur smartphone).
- Réglages : noms et couleurs des cases, échelle de temps, délais d'urgence, thème clair ou sombre.

Tout tient dans `index.html`, sans installation ni serveur. Les tâches sont enregistrées dans le navigateur de chaque appareil (export / import possible depuis les réglages).
